# Skill: PLANO (Planejador Estratégico)

Este módulo habilita a capacidade de criar planos de execução técnica de alto nível, estruturados para garantir o sucesso de tarefas complexas de desenvolvimento.

## 🎯 Objetivo
Transformar requisições ambíguas ou complexas em um roteiro (roadmap) técnico claro, detalhado e livre de ambiguidades, priorizando a segurança do código e a eficiência da implementação.

## 📋 Estrutura do Plano
Sempre que esta skill for ativada, o plano gerado deve seguir rigorosamente esta estrutura:

1.  **Contexto e Análise**:
    *   Breve resumo do estado atual do sistema relacionado à tarefa.
    *   Identificação de arquivos, módulos ou dependências que serão impactados.

2.  **Arquitetura e Design (Se aplicável)**:
    *   Descrição de novas classes, componentes ou fluxos de dados.
    *   Justificativa para as escolhas técnicas.

3.  **Etapas de Implementação (Fases)**:
    *   **Fase 1: Preparação** (Configurações, instalações, backups).
    *   **Fase 2: Núcleo** (Mudanças principais no código).
    *   **Fase 3: Refinamento** (Estilização, UX, otimização).

4.  **Plano de Verificação e Testes**:
    *   Comandos específicos para testar (unitários, integração).
    *   Checklist manual para validação visual ou funcional.

5.  **Riscos e Mitigações**:
    *   Identificação de possíveis "breaking changes" e como revertê-las se necessário.

## 💎 Diretrizes de Lapidação (Refinamento)
*   **Clareza Máxima**: Use frases curtas e diretas.
*   **Sinalização Visual**: Use blocos de alerta do GitHub (`> [!IMPORTANT]`, `> [!TIP]`) para destacar pontos críticos.
*   **Links Diretos**: Sempre que mencionar um arquivo, use o link markdown para o caminho absoluto (se conhecido) ou relativo.
*   **Código de Exemplo**: Se uma mudança for complexa, inclua um pequeno snippet do "antes e depois" planejado.

## 🚀 Como Invocar
"Baseado na skill PLANO, crie um roteiro para [descrição da tarefa]" ou simplesmente "Ative a skill PLANO para este pedido".
